# CodeAlpha_Calculator

Calculator built with HTML, CSS, and vanilla JavaScript (CodeAlpha Frontend Task 2).

## Features
- Addition, subtraction, multiplication, division with chained operations
- Live result display with running expression
- AC, Delete, plus/minus, and percent
- Divide-by-zero handling and floating-point rounding (0.1 + 0.2 = 0.3)
- Full keyboard support: digits, operators, Enter, Backspace, Esc
- No use of eval()

## Run
Open `index.html` in a browser.
