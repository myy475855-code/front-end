# CodeAlpha_ImageGallery

Responsive image gallery built with HTML, CSS, and vanilla JavaScript (CodeAlpha Frontend Task 1).

## Features
- Responsive CSS grid layout
- Lightbox with next/previous buttons, arrow keys, Esc to close, and swipe on touch screens
- Hover zoom, dim, and caption transitions
- Category filters (All, Nature, Mountains, City)
- Keyboard accessible, supports dark mode and reduced motion

## Run
Open `index.html` in a browser (internet needed for the sample photos from picsum.photos).
To use your own photos, edit the `photos` array in `index.html`.
